# DR Detect – Diabetic Retinopathy Detection System

## Overview

DR Detect is an AI-powered web application that assists in the early screening of Diabetic Retinopathy (DR) using retinal fundus images. The system leverages a fine-tuned MobileNetV2 deep learning model to classify disease severity and provides Grad-CAM visualizations to improve prediction interpretability.

The platform allows users to upload retinal images or capture them directly through a webcam, making the screening process accessible and user-friendly.

---

## Problem Statement

Diabetic Retinopathy is one of the leading causes of vision impairment among diabetic patients. Early diagnosis is essential for preventing severe complications, but access to specialized retinal screening may not always be available.

This project explores the use of Artificial Intelligence and Computer Vision to support preliminary diabetic retinopathy screening through automated retinal image analysis.

## Features

* 🔍 AI-powered diabetic retinopathy classification

* 🔥 Grad-CAM visualization for model interpretability
* ⚡ Real-time prediction interface
* 🌐 Web-based deployment for easy accessibility
* 📊 Classification across five disease severity levels

---

## Disease Classification

The model predicts one of the following diabetic retinopathy stages:

| Class            | Description                                     |
| ---------------- | ----------------------------------------------- |
| No DR            | No signs of diabetic retinopathy                |
| Mild             | Early-stage retinal abnormalities               |
| Moderate         | Noticeable retinal damage                       |
| Severe           | Advanced retinal abnormalities                  |
| Proliferative DR | Most severe stage requiring immediate attention |

## How to Use

1. Upload a retinal fundus image (PNG, JPG, JPEG).
2. Alternatively, capture an image using the webcam.
3. Click **Predict**.
4. View the predicted diabetic retinopathy stage.
5. Analyze the generated Grad-CAM heatmap for visual explanation.

---

## Model Explainability

To improve transparency, the system generates Grad-CAM visualizations that highlight regions of the retinal image that most influenced the model's prediction. This helps users understand how the model arrived at its classification.
